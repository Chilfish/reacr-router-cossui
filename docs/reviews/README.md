## 审查方式

- 建议采用多轴视角：安全 / 授权 / 正确性 / 资源纪律 / 工程文化 / UI 体验
- 对照 `docs/postmortem/README.md` 的高频雷区自查已修/复现
- 上轮问题逐条核验，避免「审了不改」
