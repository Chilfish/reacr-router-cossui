## 跨切片教训

### 经常出现的根因

1. **缺少 spike/验证**：假设未经独立环境验证
2. **缺少统一模板/清单**：重复造轮子，每次遗漏相同的东西
3. **API 边界不显式**：系统中隐式的 contract boundary 容易被忽略

### 做对了的事

1. **快速定位根因**
2. **集中修复**
